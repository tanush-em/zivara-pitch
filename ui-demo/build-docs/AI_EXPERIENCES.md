# ZIVARA AI EXPERIENCES

AI is a premium discovery layer, not a generic chatbot.

## AI Stylist
Inputs: occasion, outfit/saree, style, budget, heaviness, rental/buy.
Outputs: 3 looks, explanations, products, price, shop, relevance.

Demo prompt:
“I have a pink Kanchipuram saree for my cousin’s wedding. Traditional but not too heavy. Under ₹4,000 rental.”

## Visual Search
Image input → fake analysis → similar products. Show visual/style/colour match scores.

## Saree Matcher
Image → fake palette → style interpretation → jewellery recommendations → complete look.

## Natural-language search
Interpret occasion + type + style + price + rent/buy + location. Example: “traditional jewellery under 3000 for a reception.”

## Recommendation demo scoring
occasion .25 + style .25 + budget .20 + colour .15 + popularity .15.
Do not claim this is a production ML model.

## Marketplace intelligence
Admin insight cards: demand increase, supply gap, popular style, price opportunity, shop opportunity.

Example:
“Temple jewellery searches increased 28% this week while matching inventory remains limited.”

## AI UX
Processing messages:
- Understanding your occasion
- Matching styles
- Checking nearby collections
- Building your look
Use 800–1500ms demo transitions.
