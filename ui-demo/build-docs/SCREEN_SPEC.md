# ZIVARA SCREEN SPECIFICATION

## Consumer

### C01 Home
Editorial hero, ZIVARA branding, natural-language search, occasion chips, trending in Chennai, masonry discovery, shop-by-occasion, complete looks, rental-price collection, new arrivals, featured stores, AI Stylist CTA, nearby shops, editorial inspiration.

### C02 Explore
Pinterest-style masonry containing products, looks, editorial cards, shops, collections and AI recommendations. Filters and search.

### C03 Search
Natural-language search such as “traditional jewellery under ₹3000”, “temple jewellery for wedding”, “pink saree jewellery”. Expose interpreted filters.

### C04 Filters
Occasion, jewellery type, style, price, rent/buy, location, colour, availability date, shop, material/finish.

### C05 Jewellery Detail
Large image gallery, save, name, rental price, purchase price, deposit, availability, date picker, shop, distance, reserve, buy/enquire, contact/WhatsApp simulation, similar products, complete look.

### C06 Looks
Editorial complete looks with occasion, style, pieces, prices, bundle rental price, savings, save/share.

### C07 Look Detail
Large editorial composition; open individual pieces; rent look; enquire; save.

### C08 Shops
Local shop discovery with image, name, locality, rating, product count, categories, rental/purchase availability.

### C09 Shop Detail
Store hero, location, rating, hours, about, categories, map placeholder, reviews, catalogue.

### C10 Wishlist
Jewellery / Looks / Shops.

### C11 Profile
Saved jewellery, looks, booking/rental history, recently viewed, AI preferences, settings.

### C12 Booking
Select dates → availability → details → review → simulated reservation → confirmation → contact shop.

### C13 AI Stylist
Guided inputs: occasion, outfit/saree, style, budget, heaviness, rental/buy. Return 3 recommended looks with reasoning.

### C14 Visual Search
Image upload/drop → processing → similar jewellery + match scores.

### C15 Saree Matcher
Image upload/select demo → palette → recommendations → complete look.

### C16 Natural Language Discovery
Prompt → interpreted constraints → visual result feed.

## Retailer
R01 Dashboard: KPIs, performance, top products, enquiries, upcoming rentals.
R02 Inventory: status, pricing, views, enquiries, availability.
R03 Product Editor: images, metadata, prices, deposit, availability, tags.
R04 Bookings: New → Confirmed → Picked Up → Rented → Returned → Completed.
R05 Enquiries: customer, product/date, intent, status.
R06 Calendar: upcoming reservations.
R07 Analytics: views, enquiries, bookings, revenue, conversion, demand.
R08 Profile: shop details/storefront preview.

## Admin
A01 Overview: active shops, products, customers, bookings, GMV, Zivara revenue.
A02 Shops: approve/suspend/feature/inspect.
A03 Products: pending/approved/rejected/flagged.
A04 Customers.
A05 Bookings.
A06 Leads: views → enquiries → qualified → booking → completed.
A07 Revenue: GMV/commission.
A08 Marketplace Intelligence: demand, supply gaps, price opportunities, emerging styles.

## Responsive
Consumer must work at 390px, 768px and 1440px. Retailer/admin desktop-first but usable on tablet.
