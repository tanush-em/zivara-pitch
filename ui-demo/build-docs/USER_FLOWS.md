# ZIVARA USER FLOWS

## Discovery
Home → Explore → Search/Filter → Product → Save / Reserve / Enquire.

## Rental
Product → Reserve → Dates → Availability → Details → Review → Simulated reservation → Confirmation → Contact shop. No real payment.

## Purchase
Product → Buy/Enquire → simulated checkout OR reserve for store visit OR contact shop.

## Complete Look
Home/Explore → Look → Pieces → individual product OR rent complete look.

## AI Stylist
AI Stylist → occasion → outfit → style → budget → AI processing → 3 recommendations → look → reserve/enquire.

## Visual Search
Upload → analysis animation → similarity results → product → reserve/save.

## Saree Matcher
Upload/select → palette → recommendations → complete look → save/reserve.

## Shops
Shops → Shop → catalogue → Product → reservation/enquiry.

## Retailer
Retailer → Dashboard → Inventory → Product → Booking → Confirm → Analytics.

## Admin
Admin → Overview → Shops/Products/Bookings/Leads → Intelligence.
