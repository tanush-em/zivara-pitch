# ZIVARA IMAGE MANIFEST

## Strategy
Use web-sourced imagery where usage rights permit. Prefer Unsplash, Pexels, Wikimedia Commons, or authorized/owned imagery. Do not indiscriminately scrape copyrighted ecommerce catalogues.

For a public release, verify each source/license and replace uncertain assets with owned/licensed imagery.

## Required visual categories
Indian bridal jewellery, imitation/fashion jewellery, temple jewellery, Kundan/Polki-inspired pieces, jhumkas, bangles, chokers, complete bridal sets, Indian wedding/editorial styling.

Avoid visible luxury brand logos, counterfeit branded jewellery, watermarked images, or imagery that falsely implies a third-party business is a Zivara partner.
