# ZIVARA ADMIN SPEC

Admin is the marketplace control tower.

## Overview
Active shops, listed products, customers, bookings, GMV, Zivara revenue, commission.

## Marketplace health
Bookings/day, enquiry conversion, active inventory, new shops, pending approvals.

## Shops
Shop, locality, products, views, enquiries, bookings, revenue, status.
Actions: inspect, approve, suspend, feature.

## Products
Moderation: pending, approved, rejected, flagged.

## Bookings
Global booking list.

## Leads
Views → Enquiries → Qualified → Booking → Completed.

## Revenue
GMV, commission, shop earnings.

## Marketplace Intelligence
Demand trends, supply gaps, price bands, underperforming categories, emerging styles.
