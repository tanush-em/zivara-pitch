# ZIVARA DESIGN SYSTEM

## Direction
Modern Indian luxury + Pinterest softness + editorial jewellery photography.

Avoid wedding-template aesthetics, excessive maroon/gold, generic SaaS purple/blue, and over-carded layouts.

## Palette
--zivara-ivory: #F8F5EF
--zivara-paper: #FFFCF7
--zivara-ink: #211D1A
--zivara-muted: #776F67
--zivara-line: #E5DED4
--zivara-gold: #A98245
--zivara-dark: #171411

Gold is an accent.

## Type
Editorial serif for major headlines; clean sans for UI.
Suggested: Cormorant Garamond / Playfair Display + Inter / Manrope.

## Imagery
Images dominate. Prefer 4:5 / 3:4 portrait images for masonry, 1:1 compact product cards, 16:9 or 4:3 editorial banners. Product cards are image-first. Use subtle zoom; avoid hard borders around every image.

## Layout
Desktop: generous whitespace, ~1440px max width, asymmetric masonry, editorial full-width sections.
Mobile: 16px padding, two-column masonry, bottom nav, horizontal chips, bottom-sheet filters.

## Motion
Use Framer Motion or equivalent. 180–300ms transitions, subtle masonry entrance, 1.02–1.04 image hover zoom, slide-up filters, AI processing animation, wishlist microinteraction. Avoid excessive parallax/bouncing.

## Navigation
Mobile: Home / Explore / Shops / Wishlist / Profile.
Desktop: ZIVARA / Discover / Jewellery / Looks / Shops / AI Stylist / Wishlist / Profile.

## Cards
Image first. Product name, rental/buy price, optional availability/shop. Do not expose every metadata field.

## Brand
Strong visible ZIVARA wordmark. Branding must never overpower jewellery imagery.
