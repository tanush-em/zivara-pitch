# ZIVARA RETAILER SPEC

The retailer surface represents the future Zivara Retailer OS.

## Dashboard
KPIs: revenue generated, views, enquiries, bookings, conversion.
Secondary: booking timeline, top products, recent enquiries, upcoming rentals.

## Inventory
Table/grid toggle. Product image, name, rental, purchase, availability, views, enquiries, status.
Actions: edit, duplicate, archive, preview.

## Add Product
Images, name, category, style, occasion, rental price, purchase price, deposit, availability, description, tags.

## Bookings
Status workflow: New → Confirmed → Picked Up → Rented → Returned → Completed.
Demo status transitions must work.

## Enquiries
Open, reply simulation, mark contacted, convert to booking.

## Analytics
Views, enquiries, bookings, revenue, conversion, top category/product, demand by occasion.

UX principle: operational clarity over decoration while retaining subtle Zivara luxury cues.
